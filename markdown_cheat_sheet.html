Headings & Anchors

# H1 — the post title
## H2 — a major section
### H3    #### H4    ##### H5    ###### H6

Setext style (H1 / H2 only):
Chapter One
===========
A subsection
------------

Most engines turn each heading into an anchor id,
so you can link to it:  [jump](#a-major-section)

Code & Highlighting

Inline: `const x = 1`

Fenced block — name the language to highlight:
```js
function greet(name) {
  return `Hello, ${name}`
}
```

```python
def greet(name):
    return f"Hello, {name}"
```

Show literal backticks by fencing with more:
````
```not a real fence```
````

Blockquotes & Callouts

> A blockquote — good for pull quotes.
> — Author Name
>
>> a quote within a quote.

GitHub-style alerts (callouts):
> [!NOTE]      useful information
> [!TIP]       a helpful suggestion
> [!IMPORTANT] the key takeaway
> [!WARNING]   proceed carefully
> [!CAUTION]   risk of error

Rules & Line Breaks

A paragraph is one or more lines; separate
paragraphs with a single blank line.

End a line with two trailing spaces  ←
to force a hard line break,
or end it with a backslash \

Horizontal rule — 3+ on a line of their own:
---         ***         ___

Front Matter

At the very top of a post, between two --- fences, most engines (Hugo, Jekyll, Astro, 11ty) read metadata that controls how the post is published.

---
title: "My First Post"
date: 2026-06-03
draft: false
tags: [markdown, writing]
description: A short summary for previews & SEO.
cover: /img/cover.jpg
---

Math (LaTeX)

Many blogs render math with KaTeX or MathJax.

Inline:  the relation $E = mc^2$ sits in a sentence.

Block:
$$
\int_{a}^{b} f(x)\,dx = F(b) - F(a)
$$

Handy:  \frac{a}{b}   \sqrt{x}   \sum_{i=1}^{n}   \alpha \beta

Footnotes & Definitions

Footnotes keep asides out of the main flow.[^1]
Name them for clarity.[^src]

[^1]: The first note, rendered at the bottom.
[^src]: With an automatic back-link to the text.

Definition list (extended Markdown):
Markdown
:   a lightweight markup language for writing

Blog
:   a regularly updated site, newest first
